
 📊 Sales & Revenue Analysis Dashboard

An interactive Data Analytics dashboard built using Python, Streamlit, and Plotly to analyze and visualize business sales and revenue trends. This project helps businesses track Key Performance Indicators (KPIs),discover top-performing products, and understand sales channels across different regions.

##Features
1.Dynamic Data Loading: Supports CSV and Excel file uploads dynamically.
2.KPI Metrics Tracking:Real-time calculation of Total Revenue, Total Profit, Items Sold, and Profit Margins.
3.Interactive Slicers & Filters:Filter data on the fly by Region and Product Category.

##Interactive Visualizations:
  i)Line Chart:Revenue Trend Over Time.
  ii)Horizontal Bar Chart:Top 10 Products by Revenue.
  iii)Pie Chart: Revenue Share by Category.
  iv)Grouped Bar Chart:Regional Sales by Distribution Channel.
 v)Data Preview:Interactive table to view and inspect filtered data records.


## Tech Stack
-Language: Python
-Framework: Streamlit (For Web UI/Dashboard)
-Data Manipulation:Pandas
-Data Visualization: Plotly Express
